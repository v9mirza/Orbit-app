# Orbit

Orbit is an offline-first personal workspace for Android and iOS, built with Expo Router, React Native, TypeScript, and Expo SQLite. It brings tasks, habits, notes, expenses, and an overview into one app. Personal records are stored locally on the device.

**Official website:** https://orbit.v9mirza.com/



## Features

- First-launch onboarding and a repeatable app tour.
- Local SQLite storage for transactions, budgets, notes, tasks, habits, categories, settings, and activity.
- Search, filters, charts, recurring tasks, and habit streaks.
- JSON backup export and restore from Settings.

The source artwork is `orbit-logo.png`. Regenerate the in-app logo, launcher icons, and splash image with `node scripts/generate-assets.cjs`.
